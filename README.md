# ai-recruiter

Мультиагентная система семантического ранжирования и скоринга кандидатов.

Загружаешь вакансию, система через векторный поиск отбирает топ кандидатов из базы резюме, а LLM-агенты проводят аудит и выдают карточку с процентом соответствия, плюсами, минусами, рисками и вердиктом (Рекомендован / В резерв / Отказ).

## Актуальность

Классический поиск по ключевым словам не понимает контекста и синонимов: кандидат, написавший «разрабатывал архитектуру распределённых систем на Go», может не попасть в выдачу по жёсткому тегу «Backend Engineer» или «Golang». При этом рекрутеру важен не просто отсортированный список, а текстовое обоснование: почему конкретный человек подходит под сложные требования вакансии. Система переводит резюме и вакансию в семантические эмбеддинги для предварительного ранжирования, а затем команда LLM-агентов проводит построчный аудит топ-кандидатов и формирует экспертное заключение.

### Почему это актуально для МТС

Крупные ИТ-компании, включая МТС, получают тысячи откликов на вакансии, а первичным отбором и сортировкой резюме занимаются рекрутеры и нанимающие инженеры. Автоматический семантический скрининг снимает рутинную нагрузку с команды найма, сокращает time-to-hire и снижает риск пропустить сильного кандидата из-за несовпадения формулировок в резюме и вакансии. Решение строится на open-source LLM и локальном векторном поиске, поэтому его можно развернуть on-premise без передачи персональных данных кандидатов во внешние сервисы.

### Личная мотивация автора

Я несколько раундов отбирала кандидатов на реальную позицию Middle/Senior QA Automation в свою команду и вручную отсматривала десятки резюме. Это стало отправной точкой: захотелось сделать ai-рекрутера, который помог бы в первичном скрининге. Тестировать систему планирую на реальных выгрузках резюме кандидатов (не публикуются в репозитории из-за персональных данных).

## Стек

Python, sentence-transformers (эмбеддинги), ChromaDB (векторный поиск), Ollama или облачный LLM API (агенты), Pydantic (контракты).

## Структура

- **Парсинг резюме** (`ai_recruiter/parsing`) — извлечение текста из PDF/DOCX/ODT/TXT.
- **Чанкинг** (`ai_recruiter/chunking`) — нарезка текста по секциям (опыт, навыки, образование и др.).

Система ориентирована на классические выгрузки резюме с hh.ru: парсинг формата-агностичный, а чанкинг распознаёт стандартные заголовки секций hh.ru (русские и английские).
- **Эмбеддинги и векторный поиск** (`ai_recruiter/embeddings`) — индексация чанков в ChromaDB.
- **Тулы** (`ai_recruiter/tools`) — `semantic_search`, `extract_experience_years`, `check_mandatory_skills`.
- **Агенты** (`ai_recruiter/agents`) — Технический Скринер и HR-Аналитик.
- **Отчёт** (`ai_recruiter/report`) — карточка кандидата с вердиктом.
- **Данные** (`ai_recruiter/data`) — воспроизводимый генератор демо-резюме (PDF/DOCX) с фиксированным seed.
